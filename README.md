# StarArtist

A drawing puzzle game about making weird 5-pointed stars.

## Concept

A valid 5-pointed star is a drawing with exactly 6 enclosed shapes:
one central pentagon, plus 5 triangles, each sharing one side with the pentagon.
No extra line segments allowed.

Each level gives you a partial drawing and a limited line budget.
Finish the star.

## Status

Very early. Currently just project scaffolding.

## Run it

```
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.
